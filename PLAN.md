## Steps

- [ ] **1. Fix the handler so that it takes only the pathname of `req.url` (the query string is stripped before resolving, so `/style.css?v=1` serves `style.css`), resolves it against `publicDir`, and answers 404 without touching the file system when the resolved path is not inside `publicDir` (compare with a trailing separator or `path.relative`, so a sibling such as `public-old` does not pass a bare prefix check).
